# 市寬狀態與新倉政策

> 來源：交接文件 §12。

## 已確認方向

| 狀態 | 新倉政策方向 |
| :-- | :-- |
| 正常 | A 為主，B 合條件才用；正常目標配置 |
| 轉弱 | 只准強 sector 的合格 A；暫停 B；可縮小配置 |
| 中線明顯轉差 | 進一步限制新倉，或等待星期日覆盤 |
| 恢復正常 | 經確認後恢復正常政策 |

共通：

- 1.5% 單筆硬上限不變。
- 不因市寬轉弱自動減持現有倉位。
- 不因帳戶回撤單獨自動停開新倉。
- Sector rotation 不等於必須換馬。
- 不因單日讀數任意切換狀態。

## 使用者提出過的切換草案：尚未完整鎖定

### 正常

- %SMA50 ≥50%。
- 較一週前沒有明顯下跌。
- %SMA200 最好亦 ≥50%。
- 新高不少於新低。

### 轉弱

- %SMA20 較前日及一週前均下跌。
- %SMA50 仍 ≥50%，或只是輕微回軟、未持續惡化。
- 或指數不跌／創新高，但短線廣度開始回軟。

### 中線明顯轉差

- %SMA50 較一週前下跌。
- 並跌穿或已低於 50%。
- 再加至少一項確認：
  - %SMA200 下跌或低於 50%。
  - 新高／新低轉差。
  - RSP 明顯跑輸 SPY。
- 草案亦提過「指數創新高但 %SMA50 下跌」屬背馳轉差。

### 恢復正常

- 不因單日反彈就恢復。
- %SMA50 較一週前回升，並重返 50%。
- 草案亦提出過以「%SMA200 ≥50% 且企穩」作替代路徑。
- %SMA20 不再同步惡化。
- 最好連續數日，或星期日確認。

## 尚待解決（見 decisions-needed.md）

背馳是否足以單獨觸發「中線明顯轉差」；%SMA200 企穩是否可取代 %SMA50 恢復；「明顯」「持續」「輕微」「企穩」的定義；NH／NL 轉差的計算方式；RSP 跑輸的回看期及幅度；多個狀態同時符合時的優先次序；是否必須連續多日確認；星期日確認與平日切換的關係；恢復 A 正常配置與恢復 B 是否分階段。

曾提出但未獲使用者鎖定的建議：背馳但 %SMA50 仍高於 50%，先列轉弱警號；恢復正常必須重新符合正常狀態的基本資格，不單靠 %SMA200。

## 縮倉與限制筆數：待定
