# Bots 分工

> 來源：交接文件 §2.2 及 2026-11-16 凌晨討論。

| 角色 | 工作 |
| :-- | :-- |
| 使用者 | 決定及批准規則；將來親自交易 |
| Grok Bot（新 Bot，執行者） | 接手項目規劃、規則整理、待辦追蹤及後續流程落地；按 repo 確認咗嘅規則運作，做每日覆核同星期日覆核。實際自動化能力須另行驗證 |
| Perplexity | Ad hoc 分析、研究、規則討論及個別問題檢視 |
| 舊投資 Bot（顧問，凍結） | 只按舊有規則畀意見，唔執行、唔改規則、唔寫新系統 state 檔；意見經使用者／助理 Bot 傳話，兩個 bot 唔直接溝通 |
| 個人助理 Bot | 對話、接收決定、派任務、匯報進度；唔做分析，唔發明交易決定 |

不得假定任何 AI 已具備持續排程、交易執行、資料存取或背景監察能力。

新 Bot 嘅 instruction prompt：`../files/新Paper_Trade_Bot_Instruction_Prompt.md`（開 repo 嗰陣搬入 `docs/prompts/`）。

新 Bot 啟動條件：使用者確認 Strategy v1 草稿準確記錄規則，同埋決定星期日覆核用唔用 time-review ladder。未確認之前，只可以做準備，唔可以做交易判斷。
