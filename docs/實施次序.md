# 後續工作次序

> 來源：交接文件 §15。上次助理提出的建議排序，並非所有步驟已獲使用者逐項批准。

## 階段一：完成入場執行規格

1. 定義 A 的 trigger。
2. 定義 B 的 trigger。
3. 定義計股數用的參考入場價。
4. 定義分鐘觸發條件。
5. 處理開市已越過 trigger。
6. 設定價格偏離／最高可接受入場價及取消條件。
7. 處理最後一分鐘觸發及資料缺漏。
8. 確認交易時段、成本及滑價模型。

## 階段二：完成資金及持倉限制

1. 解決空倉起步的 sector 限制矛盾。
2. 定義帳戶值快照。
3. 定義未成交計劃資金預留。
4. 定義多筆同日觸發的優先次序。
5. 定義固定股數下的資金不足處理。
6. 定義 sector 檢查的計算時點。

## 階段三：完成持倉管理

1. 核對 +2R 減半安排。
2. 定義奇數股處理。
3. 定義止蝕／止賺模擬成交。
4. 定義 ATR trailing 完整規格。
5. 定義更新時間及生效時間。
6. 定義同分鐘衝突事件。
7. 核對其他退出條件。

## 階段四：完成選股與市寬規則

1. 鎖定流動性閘。
2. 鎖定 RS 算法。
3. 鎖定 sector 強弱定義。
4. 補齊 A／B 形態定義。
5. 完成市寬狀態切換。
6. 決定 70%–80% 比例及基準。
7. 決定「最多一筆」的期間及條件。

## 階段五：驗證資料及落地保存

1. 驗證工具及授權。
2. 測試日線與分鐘線取得能力。
3. 驗證市寬資料與計算口徑。
4. 建立規則、狀態及差異檔。
5. 建立不可事後改寫的每日計劃。
6. 建立回放及交易日誌。

資料能力可提前作小規模檢查，但不可反過來把工具限制默默改成交易規則。

## 階段六：小規模流程測試

至少涵蓋：未觸發；正常觸發及成交；開市跳空越過 trigger；價格偏離而取消；多隻同日觸發；資金不足；Sector 限制不通過；入場後止蝕；到達 +2R；同一分鐘觸及多個相關價位；分鐘資料缺失；假期／跨時區日期；奇數股減半；規則版本變更。

先確認流程可重複，再進入持續 paper trading；不要用少量短期盈虧直接判定策略成敗。
