# 資料來源與工具

> 來源：交接文件 §13。資料來源決定未定（見 `decisions/decisions-needed.md`：TradingView 定 Alpaca）。

## 已決定

- 不使用 StockCharts 作本項目的自動化資料來源。
- 原因是其自動存取政策在未經批准情況下可能有合規問題。
- 不應以繞過網站限制方式取得資料。

## 待驗證：TradingView MCP

以下能力尚未逐項驗證：

- 每週候選股票池建立。
- 美股日線 OHLCV。
- 歷史 1 分鐘 OHLCV。
- 分鐘資料歷史範圍及缺失情況。
- Wilder ATR14。
- 11 個 sector ETF 與 SPY 的比較。
- S&P 500 成分股名單。
- %SMA20／50／200。
- 52 週 NH／NL。
- A-D Line。
- RSP／SPY。
- 資料保存、匯出、配額及自動化權限。

不能因某個工具有技術指標或圖表功能，就假定能完成整個項目。

## 時間框架分工

| 資料 | 用途 |
| :-- | :-- |
| 日線 | 股票池、趨勢、RS、A／B 訊號、ATR、市寬 |
| 1 分鐘線 | Day2 觸發、模擬成交及成交後事件回放 |
| 帳戶／持倉紀錄 | 資金、sector、股數及績效核算 |

只用日線不足以還原目前約定的下一分鐘成交模型。
